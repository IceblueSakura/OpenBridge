# 实施计划

本目录按用户可见功能组织尚待实施或仍待验证的设计，不表示固定阶段、实施顺序或完整路线图。每次实现只在[当前开发焦点](current-focus.md)中选择一个可观察行为并先写失败测试。

| 功能 | 文档 |
|---|---|
| 当前单一行为 | [当前开发焦点](current-focus.md) |
| 服务边界与路径选择 | [服务架构](service-architecture.md) |
| 配置、路由与使用量 | [配置与路由](configuration-and-routing.md) |
| Provider 接入与数据流 | [Provider 适配与数据流](provider-adapters-and-dataflow.md) |
| 客户端兼容 | [客户端兼容](client-compatibility.md) |
| Chat/Responses 转换 | [协议桥](protocol-bridge.md) |
| Agent tool-loop 状态 | [Agent Loop Bridge](agent-loop-bridge.md) |
| 可选 OAuth 凭证 | [OAuth 凭证边界](oauth-credential-boundary.md) |

当某项计划被实现并验证后，将可证明的结论转入 `../implementation-status/`；不在本目录保留目标变迁、淘汰方案或旧阶段记录。
