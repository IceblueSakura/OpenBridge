# 实施计划

本目录只有[当前开发焦点](current-focus.md)可以表示已获准实施的短周期行为。当前焦点中的 P0-P3 是现有获准范围，
本文不复制其内容，也不以其他计划、清单或状态页扩大授权。

除当前焦点外，本目录不保存远期设计、候选类型、测试缺口清单、阶段路线图或已经完成的架构说明。尚未进入当前焦点的行为
只能留在功能需求的非目标、实施现状的未证明边界或外部参考中，不能构成实施授权。

开始下一项工作时：

1. 先读取 live source、工作区状态、[功能需求](../functional-requirements/README.md)
   与[实施现状](../implementation-status/README.md)；
2. 只选择一个可观察行为，在 `current-focus.md` 写明需求、失败测试、不做项和验证边界；
3. 实现并验证后，将事实写入 `implementation-status/`，再把 `current-focus.md` 恢复为空焦点；
4. 没有进入当前焦点的条目不构成实施授权，不得从状态文档、参考资料或历史记录推导新的实施范围。
