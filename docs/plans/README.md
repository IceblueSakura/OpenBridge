# 计划目录

本目录只保存当前执行计划，不保存完整路线图。

- [`implementation-plan.md`](implementation-plan.md) 必须只覆盖一个 `Active` 阶段；
- 长期产品范围见[核心需求](../requirements/proxy-requirements.md)；
- 跨阶段目标与证据门见[阶段交付与研究需求](../requirements/delivery-requirements.md)；
- 各阶段的进入条件、非目标和退出条件见[阶段契约](../phases/README.md)。

当前阶段关闭后，应先将其状态更新为 `Accepted`，再用下一阶段的新基线替换当前计划。禁止在同一计划中追加后续 phase。
